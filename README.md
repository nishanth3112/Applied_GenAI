# Applied Generative AI

This repository contains coursework, hands-on exercises, experiments, and application development related to **Generative AI (GenAI)** and **Agentic AI**.

## 📖 Course Overview

This course examines how **Generative AI (GenAI)** and autonomous **Agentic AI systems** leverage **Large Language Models (LLMs)** to extract insights, generate solutions, and address complex, multi-faceted problems.

The course emphasizes hands-on exploration and practical development of AI-driven applications across diverse domains, including:

* Healthcare
* Supply Chain Optimization
* Financial Decision-Making
* Strategic Planning

The course provides opportunities to design, deploy, and apply **GenAI-powered analytical tools and applications**, alongside goal-oriented **Agentic AI systems**.

Key topics include **Prompt Engineering, Model Fine-Tuning, Retrieval-Augmented Generation (RAG), GenAI Ethics**, and emerging trends in the AI industry.

> **Note:** This is an application-focused course. Rather than deeply exploring the fundamental theories behind LLMs, the course emphasizes hands-on learning, experimentation, and practical implementation of Generative AI systems.

## 🎯 Course Objectives

By the end of the course, the goal is to:

* Explore the fundamentals of **Generative AI** and understand its transformative impact on engineering workflows across multiple domains.
* Gain hands-on experience solving real-world problems using **GenAI-enabled tools and applications**.
* Develop proficiency in **Prompt Engineering, Retrieval-Augmented Generation (RAG)**, and other techniques for enhancing AI capabilities.
* Progress from preliminary **GenAI-assisted applications** toward more advanced **Agentic AI systems**.
* Build familiarity with tools and platforms used for AI orchestration, workflow automation, and interactive application development.
